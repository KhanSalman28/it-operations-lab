# IT Operations Lab

A hands-on technical portfolio documenting practical IT operations, infrastructure administration, troubleshooting, and security-aware operational practices across Windows, Linux, networking, and virtualization environments.

## Overview

This repository focuses on the operational foundations that support modern IT infrastructure and security operations.

The work documented here emphasizes:

* Structured troubleshooting
* Evidence-based investigation
* Windows administration
* Linux administration
* Network operations
* Virtualization
* System and service management
* Log analysis
* Operational documentation
* Security-aware infrastructure practices

The objective is to demonstrate practical technical problem-solving rather than simply document theoretical concepts.

## Lab Areas

| Area               | Focus                                                    |
| ------------------ | -------------------------------------------------------- |
| **Windows**        | Event logs, services, users, PowerShell, troubleshooting |
| **Linux**          | Administration, permissions, services, processes, logs   |
| **Networking**     | TCP/IP, DNS, DHCP, connectivity, diagnostics             |
| **Virtualization** | Virtual machines, networking, resources, infrastructure  |
| **Case Studies**   | Structured investigations and root-cause analysis        |
| **Documentation**  | Troubleshooting methodology and operational procedures   |
| **Diagrams**       | Infrastructure and investigation workflows               |

## Investigation Methodology

Technical investigations follow a structured workflow:

```text
Problem / Objective
        ↓
Environment & Scope
        ↓
Evidence Collection
        ↓
Analysis
        ↓
Hypothesis Testing
        ↓
Root Cause / Finding
        ↓
Remediation
        ↓
Verification
        ↓
Documentation
```

This methodology is intended to make technical work reproducible and demonstrate how operational problems can be investigated systematically.

## Security Perspective

Although this repository focuses on IT operations, security considerations are incorporated into the work wherever relevant.

Examples include:

* Authentication and authorization
* Least privilege
* System and network hardening
* Security-relevant logging
* Suspicious activity identification
* Access control
* Service exposure
* Configuration weaknesses
* Detection opportunities

These operational foundations provide the infrastructure knowledge required for later security monitoring, detection, threat hunting, and incident-response work.

## Evidence and Reproducibility

Technical work will be supported by appropriate evidence such as:

* Command output
* Event log observations
* Configuration details
* Packet captures
* Screenshots where useful
* Investigation notes
* Diagrams
* Before-and-after verification

Sensitive information, credentials, personal data, and environment-specific secrets will not be published.
