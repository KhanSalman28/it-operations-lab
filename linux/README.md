# Linux Operations

This section documents hands-on Linux administration, troubleshooting, system management, permissions, services, processes, and security-aware operational practices.

## Scope

- Linux system administration
- Filesystem and directory management
- Users and groups
- POSIX permissions
- `sudo` and privilege management
- Processes and services
- `systemctl` and `journalctl`
- Linux log analysis
- Bash-based administration
- System troubleshooting

## Objective

Build practical experience administering and troubleshooting Linux systems while developing an understanding of the operational telemetry and security controls relevant to security operations.
