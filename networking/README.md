# Networking Operations

This section documents practical networking fundamentals, connectivity troubleshooting, network diagnostics, and security-aware network operations.

## Scope

- IPv4 addressing and subnetting
- TCP/IP fundamentals
- DNS and name resolution
- DHCP
- Default gateways and routing
- TCP and UDP
- Network connectivity troubleshooting
- Network diagnostic tools
- Packet and traffic analysis
- Basic network security considerations

## Tools

- `ping`
- `traceroute` / `tracert`
- `nslookup`
- `ipconfig`
- `ip`
- `ss`
- Wireshark

## Objective

Develop practical network troubleshooting skills and understand how network behavior, connectivity failures, and traffic patterns can be investigated from an IT operations and security perspective.
